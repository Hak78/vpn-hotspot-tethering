# 🚀 No-Root VPN Hotspot Share (HTTP Proxy) 🌐✈️

تطبيق برميجي خفيف وذكي مكتوب بلغة **Python** لمشاركة اتصال الإنترنت المؤمن بواسطة **VPN** من جهازك (مثل هواتف الأندرويد عبر تطبيق Termux) إلى أي أجهزة أخرى متصلة بنقطة الاتصال (**Wi-Fi Hotspot**)، والميزة الأكبر أنه **لا يتطلب صلاحيات الـ Root أو كسر حماية النظام**.

---

## ✨ الميزات (Features)
- **بدون روت (No Root Required):** يعمل بالكامل في بيئة المستخدم العادية دون الحاجة لأوامر `iptables` أو `sudo`.
- **دعم الأجهزة المصغرة:** متوافق تماماً مع تطبيق **Termux** على الأندرويد والتوزيعات المصغرة التي لا تحتوي على حزمة `NetworkManager`.
- **معالجة متوازية (Multi-threading):** يدعم اتصال أجهزة متعددة في نفس الوقت وبسرعة استجابة عالية بدون بطء.
- **توجيه كامل للـ VPN:** يسحب الإنترنت من جهازك الأساسي (المحمي بنفق الـ VPN الحالي) ويمرره للأجهزة المتصلة.

---

## 📋 المتطلبات الأساسية (Prerequisites)
1. بيئة تشغيل تدعم لغة **Python 3.x** (مثل Termux على الأندرويد، أو أنظمة Linux/Windows).
2. تطبيق VPN يعمل بشكل طبيعي على جهازك الأساسي.
3. تفعيل نقطة الاتصال الشخصية (**Hotspot**) من إعدادات جهازك لبث شبكة Wi-Fi للأجهزة الأخرى.

---

## 🚀 طريقة التشغيل والاستخدام (Usage Guide)

### 1️⃣ تشغيل الخادم على جهازك الأساسي:
قم بتحميل ملف المشروع وتشغيله داخل Terminal أو Termux عبر الأوامر التالية:

```bash
# تحميل المستودع من حسابك
git clone https://github.com
cd YOUR_REPO_NAME

# تشغيل التطبيق مباشرة بدون صلاحيات مسؤول
python3 app.py
```
*ستظهر لك رسالة تؤكد أن الخادم يعمل بنجاح على المنفذ `8080`.*

### 2️⃣ إعداد الأجهزة المستقبلة (الكمبيوتر، شاشة ذكية، هاتف آخر):
لتوجيه حركة مرور الجهاز الآخر عبر الـ VPN، اتبع الخطوات التالية:
1. اتصل بشبكة الـ Wi-Fi (الـ Hotspot) التي تبثها من جهازك الأساسي.
2. افتح **إعدادات الشبكة المتقدمة** في الجهاز المستقبِل.
3. ابحث عن خيار **الوكيل (Proxy)** وقم بتحويله من تلقائي إلى **يدوي (Manual)**.
4. ادخل الإعدادات التالية:
   - **اسم مضيف الوكيل (Proxy Hostname):** ضع عنوان الـ IP الخاص بجهازك الأساسي الباث (في الأندرويد يكون غالباً `192.168.43.1`).
   - **منفذ الوكيل (Proxy Port):** `8080`
5. احفظ الإعدادات.

---

## ⚙️ التخصيص (Customization)
إذا كنت ترغب في تغيير المنفذ الافتراضي (Port)، يمكنك فتح ملف `app.py` وتعديل المتغيرات في بداية الكود:
```python
PORT = 8080  # يمكنك تغييره إلى أي منفذ مفتوح آخر
```
